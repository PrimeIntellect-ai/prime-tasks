SCOPE OF CHANGES:
-----------------

1. NGINX CONFIGURATION:
   a. Enable HTTPS redirect on all HTTP traffic (port 80 -> 443).
   b. Disable server_tokens to suppress version disclosure.
   c. Block access to all dotfiles (/.env, /.git, etc.) with 403 responses.
   d. Add security headers: HSTS, X-Frame-Options (DENY), X-Content-Type-Options (nosniff).
   e. Restrict /admin/ to management network (10.200.0.0/24) only.
   f. Remove the /api/v1/debug endpoint from production.

2. FIREWALL (iptables):
   a. Remove public access to port 3000 (Node.js) — reverse proxy handles this.
   b. Remove public access to port 3001 (admin panel) — restrict to 10.200.0.0/24.
   c. Remove public access to port 5432 (PostgreSQL) — application zone only.
   d. Remove public access to port 6379 (Redis) — application zone only.
   e. Add rate-limiting rule for SSH: max 3 new connections per minute.

3. SSL/TLS:
   a. Renew the admin panel certificate (admin.shopvault-internal.com) before expiry.
   b. Retire the staging self-signed certificate and decommission staging.shopvault.example.com.
   c. Set minimum TLS version to 1.2 across all domains.

VERIFICATION:
   Post-implementation scan to confirm all changes. Assign to web operations team.
