You are the CIO at Meridian Technologies Inc. (2,847 employees, 186 IT staff). A board audit flagged data consistency issues across IT tracking systems. The CFO wants a unified assessment reconciling data across all source systems before approving cloud migration. Produce three deliverables.

The first deliverable is a Cross-System Reconciliation & Migration Readiness Report (.docx) titled "IT Operations Reconciliation & Cloud Readiness Assessment." It should open with an executive summary covering key findings, material discrepancies, and a cloud vendor recommendation. The budget variance analysis must examine spend at both the category and subcategory level, flagging any line where Q4 deviates from the Q1-Q3 average by more than 15%. Cross-reference the sum of server-level maintenance costs from the asset inventory against the corresponding budget lines and quantify the gap. For infrastructure health triage, classify each server into urgency tiers — Tier 1 (Immediate): Degraded or EOL status, or age exceeding 6 years; Tier 2 (Planned): CPU utilization below 20% and memory below 30%; Tier 3 (Standard): the remainder — and for Tier 1 servers, recommend a right-sized AWS replacement instance using publicly available AWS instance specification data from external public sources (for example, the cloud-carbon-footprint coefficients dataset). Cross-reference server hostnames against application and risk data in the database where relevant. The incident-informed risk prioritization section should correlate Critical and High risks with related ITSM incidents and report incident volume and average handle time per risk. Flag any disaster recovery plan with test failures or RTO exceeding 24 hours, and identify which Critical/High risks lack adequate DR coverage. The vendor sensitivity analysis should compare 3-Year TCO with committed-use discounts and determine which vendors remain viable if cloud costs exceed projections by 10% and 20%.

The second deliverable is an Operational Intelligence Dashboard (.xlsx) with four sheets. "Reconciled Budget" should show per-category FY2024 totals with bottom-up validation from asset data where possible, reporting deltas and flagging discrepancies above 5%. "Server Migration Matrix" lists every server with its tier assignment, recommended AWS instance for Tier 1, and current annual cost. "Risk-Incident Correlation" maps each Critical/High risk to incident count, average handle time, DR status, and affected compliance frameworks. "NIST CSF Posture" maps each question from the standard NIST Cybersecurity Framework questionnaire, obtained from external public sources such as the simplerisk assessment repository, to the organization's compliance status, related security incident count, and migration impact — marked Improved only where the risk register indicates a severity decrease, otherwise Neutral or Requires Attention.

The third deliverable is a reconciliation_flags.csv file that systematically identifies cross-system discrepancies — budget totals versus asset-level costs, risks without matching incident categories, compliance controls without NIST CSF mappings, and any other inconsistencies found across the data sources.
