An interagency review panel has flagged inconsistencies between county-level socioeconomic trends and recent health outcome shifts. Conduct an independent reconciliation analysis to determine whether structural socioeconomic changes over the past decade adequately explain the current cross-sectional pattern of county health disparities, or whether residual geographic clustering suggests unmeasured contextual factors.

The task_folder contains county-level CDC PLACES health data and USDA ERS poverty estimates only. You will also need to obtain separate USDA ERS county-level datasets covering educational attainment through 2023, population estimates with demographic components for 2020–2023, and unemployment with median household income time series through 2023.

Build a normalized SQLite database (county_analysis.db) with tables for county identifiers (including 2023 RUCC and Economic Typology), a current socioeconomic snapshot (poverty rate, median household income, unemployment rate, education attainment, population), historical socioeconomic change (unemployment change from 2010 to 2023; for income change, use the earliest and latest available years across the source files), health outcomes (all 15 CDC PLACES county measures pivoted into columns as crude prevalence), and demographic dynamics (net migration rate, natural change rate, population change for 2020–2023). Counties with incomplete joins should be logged in an exclusions table with reason codes. Index each table on FIPS.

Produce an Excel workbook (disparity_profile.xlsx) with three sheets. A Change-by-Health Matrix grouping counties into unemployment-change terciles and cross-tabulating mean prevalence for all 15 health measures with ANOVA tests. A Metro Decomposition performing Blinder-Oaxaca decomposition of the metro/non-metro gap in obesity, diabetes, and depression prevalence using pooled regression coefficients. An Outlier Flag Sheet identifying counties where observed prevalence deviates from regression-predicted values by more than 2 standard deviations of the residual, listing FIPS, county name, state, predicted value, observed value, and residual.

Build a Jupyter notebook (reconciliation_models.ipynb) that reads from county_analysis.db. Fit two competing specifications for obesity, diabetes, and depression: a static model using socioeconomic levels with RUCC controls, and a dynamic model adding change variables and net migration rate. Compare specifications using a likelihood ratio test and information criteria. For the best-fitting model of each outcome, compute Moran's I on residuals aggregated to the state level using queen contiguity to assess spatial clustering. Conduct a mediation analysis testing whether the poverty-obesity pathway operates through physical inactivity, reporting the indirect effect with bootstrap confidence intervals. Generate forest plots comparing coefficients across specifications, state-level residual maps with a diverging color scale, and a mediation path diagram.

Write a 2–3 page technical memo (reconciliation_memo.pdf) covering reconciliation findings with formal test results, spatial residual assessment, mediation insights quantifying the indirect pathway, patterns among flagged outlier counties, and limitations including ecological inference and temporal alignment across sources. Embed at least 3 figures from the notebook.
