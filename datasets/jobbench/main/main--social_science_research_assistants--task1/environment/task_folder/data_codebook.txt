
NSW REMOTE WORKING SURVEY - DATA CODEBOOK
==========================================

This codebook documents the variable definitions, valid values, and data validation rules
for the NSW Remote Working Survey dataset. Use this document to verify data accuracy.

SURVEY BACKGROUND
-----------------
Data Source: NSW Productivity Commission
Collection Period: August-September 2020 (Wave 1) and March-April 2021 (Wave 2)
Sample Size: 1,500 employed NSW residents per wave (3,000 total)
Population: "Remoteable" workers across various industries

DATA VALIDATION RULES
---------------------

1. RESPONDENT DEMOGRAPHICS (respondents table)
----------------------------------------------

Variable: responder_id
- Type: Integer
- Description: Unique identifier for each respondent
- Validation: Must be unique; no duplicates allowed; non-negative integer

Variable: birth_year
- Type: Integer (4 digits)
- Description: Year of birth
- Valid Range: 1945-2002 (workers aged approximately 18-75 at time of survey)
- Validation: Cannot be future year; cannot be before 1940; must be 4-digit year

Variable: gender
- Type: Categorical
- Valid Values: "Male", "Female"
- Validation: Must match exact spelling and capitalization; no abbreviations (M/F invalid)

Variable: industry_desc
- Type: Categorical
- Valid Values:
  - "Education and Training"
  - "Financial and Insurance"
  - "Financial and Insurance Services"
  - "Health Care and Social Assistance"
  - "Information Media and Telecommunications"
  - "Other"
  - "Other Services"
  - "Professional, Scientific and Technical"
  - "Professional, Scientific and Technical Services"
  - "Retail Trade"

- Validation: Must match one of the valid industry categories above; cannot be blank

Variable: occupation_desc
- Type: Categorical
- Valid Values:
  - "Clerical and administrative"
  - "Managers"
  - "Managers - Chief Executives, General Managers and Legislators"
  - "Managers - Specialist Managers"
  - "Other"
  - "Professionals"
  - "Professionals - Business, Human Resource and Marketing Professionals"
  - "Professionals - Design, Engineering, Science and Transport Professionals"
  - "Professionals - Education Professionals"
  - "Professionals - ICT Professionals"
  - "Sales"

- Validation: Must match one of the valid occupation categories; cannot be blank

Variable: manage_others
- Type: Categorical
- Valid Values: "Yes", "No"
- Validation: Must be exactly "Yes" or "No"

Variable: household
- Type: Categorical
- Valid Values:
  - "Couple with dependent children"
  - "Couple with no dependent children"
  - "Group household"
  - "Multiple family household"
  - "One  parent family with dependent children"
  - "One parent family with dependent children"
  - "Other one family household"
  - "Single person"

Variable: years_at_job
- Type: Categorical
- Valid Values:
  - "Between 1 and 5 years"
  - "Between 6 and 12 months"
  - "More than 5 years"

Variable: metro_or_regional
- Type: Categorical
- Valid Values: "Metro", "Regional"


2. ORGANIZATIONAL DATA (organizational_data table)
--------------------------------------------------

Variable: organization_size
- Type: Categorical
- Valid Values:
  - "Between 1 and 4"
  - "Between 20 and 199"
  - "Between 5 and 19"
  - "I am a sole trader/owner-operator"
  - "I am the only employee"
  - "More than 200"

Likert Scale Variables (Agreement Questions):
- org_encouraged_rw
- org_prepared_for_rw
- rw_is_common_at_org
- rw_permission_is_attainable
- rw_collaboration_easy
- if_no_covid_employer_encourage_rw
- if_no_covid_employer_support_rw
- if_no_covid_i_would_have_choice_about_rw

Valid Values for ALL Likert variables:
  - "Strongly agree"
  - "Somewhat agree"
  - "Neither agree nor disagree"
  - "Somewhat disagree"
  - "Strongly disagree"

Validation: Values like "Agree", "Disagree", "SA", "SD", or numeric codes are INVALID


3. TIME MANAGEMENT DATA (time_management table)
-----------------------------------------------

Remote Working Frequency Variables:
- rw_percentage_2020
- preferred_rw_percentage_2020
- preferred_rw_percentage_future

Valid Values:
  - "0-1 days"
  - "1-2 days"
  - "2-3 days"
  - "3-4 days"
  - "4-5 days"

Variable: productivity_remote_vs_office
- Type: Categorical
- Valid Values:
  - "much more productive"
  - "more productive"
  - "same productivity"
  - "less productive"
  - "much less productive"

Numeric Hours Variables:
- inperson_hours__commuting
- inperson_hours__working
- inperson_hours_domestic_responsibilities
- inperson_hours__personal_family_time
- remote_hours_commuting
- remote_hours_working
- remote_hours_personal_family_time
- remote_hours_domestic_responsibilities
- commute_time_difference

Validation for Hours Variables:
- Type: Numeric (float)
- Valid Range: 0.0 to 24.0 (hours per day)
- Cannot be negative
- Cannot exceed 24 hours per day
- Logical check: If rw_percentage is "4-5 days", remote_hours_commuting should typically be low (< 1.0)


DATA QUALITY ERROR TYPES TO CHECK
---------------------------------
1. Impossible values (future years, negative hours, hours > 24)
2. Outliers (birth years before 1940)
3. Typos (e.g., 1890 instead of 1980)
4. Inconsistent coding (M/F instead of Male/Female)
5. Missing values (blank or empty cells)
6. Invalid categorical values (not in valid set)
7. Duplicate IDs
8. Logical inconsistencies (e.g., full remote work but high in-person commute hours)
