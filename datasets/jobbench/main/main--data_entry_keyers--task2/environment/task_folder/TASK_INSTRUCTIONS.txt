You are a Data Entry Keyer at Riverside Health Partners, a medical billing company in Portland, Oregon. Your supervisor has assigned you a quality control review of 75 patient billing records entered last week. The Q1 2025 coding policy update memo and the updated fee schedule in your task folder both took effect on February 1, 2025, and your review must account for these changes.

Compare the entered billing data against the source billing forms across all data fields. Note that the source forms themselves are not guaranteed to be free of internal inconsistencies — your review should catch issues at every level, not just transcription errors. Where diagnosis codes appear, validate them against the current CMS ICD-10-CM code set to confirm that codes and their descriptions are correctly paired in both the entered data and the source documents. Locate the original FY2025 Code Descriptions in Tabular Order archive on the CMS ICD-10 codes page at https://www.cms.gov/medicare/coding-billing/icd-10-codes and obtain its official CMS ICD-10-CM FY2025 code descriptions file, icd10cm_codes_2025.txt, as the validation reference; use the release for October 1, 2024–March 31, 2025, rather than the April update.

Categorize each finding as either a clear error or an item requiring further review, following the flagging protocol described in the policy memo. Produce four deliverables: an error log using the provided template for all clear errors, a separate CSV of items flagged for review with the form ID, field name, entered and source values, and the specific reason for flagging, a corrected version of the billing data that addresses only clear errors, and a reconciliation report. The reconciliation report should contain a summary of overall results with a breakdown by error type, a provider-level view, a facility-level view using the organization's internal provider-to-facility directory, referenced in Riverside Health Partners systems as provider_facility_reference.csv, and a sheet detailing all flagged review items with references to the applicable policy rule or fee schedule entry.
