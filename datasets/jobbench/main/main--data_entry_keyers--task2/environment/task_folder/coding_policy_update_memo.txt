RIVERSIDE HEALTH PARTNERS
INTERNAL MEMORANDUM

TO:      All Data Entry Staff, Billing Department
FROM:    Patricia Langford, Compliance Officer
DATE:    January 28, 2025
RE:      Q1 2025 Coding Policy Updates — Effective February 1, 2025

This memo summarizes coding and billing policy changes effective 02/01/2025. All data entry keyers must apply these rules to claims with service dates on or after February 1, 2025.

1. ICD-10-CM CODE UPDATES
   Effective 02/01/2025, the following coding changes apply:

   a) For patients presenting with unspecified cough, use R05.9 ONLY for service dates
      BEFORE 02/01/2025. For service dates on or after 02/01/2025, use the more specific
      code R05.1 (Acute cough), R05.2 (Subacute cough), R05.3 (Chronic cough), or
      R05.4 (Cough syncope) as documented by the provider.
      If no further specification is documented, default to R05.9 but FLAG the record
      for provider clarification.

   b) For panniculitis unspecified (M79.3), this code remains valid but claims with
      service dates after 02/01/2025 should cross-reference whether M79.3 or a more
      specific site code (M79.3X1 through M79.3X9) was documented on the source form.

2. INSURANCE PROVIDER NAME STANDARDIZATION
   Effective immediately, use the following standardized names in all data entry:
   - "Blue Cross Blue Shield" (not "BCBS", "BlueCross", or "Blue Cross")
   - "UnitedHealthcare" (not "United Healthcare", "UHC", or "United Health Care")
   - "Cigna" (not "CIGNA" or "cigna")
   All existing entries should already comply; verify during QC reviews.

3. FEE SCHEDULE UPDATES
   Updated fee schedules by facility take effect for service dates on or after 02/01/2025.
   Refer to "fee_schedule_update_Q1_2025.csv" for rate changes. During QC review, note
   that billed amounts in the entered data reflect what was actually submitted to the
   insurer. The source billing forms contain the original provider-quoted amounts.
   Discrepancies between entered amounts and source amounts are NOT necessarily errors
   if the entered amount matches the updated fee schedule rate for that facility and CPT code.
   However, if neither the source amount nor the fee schedule rate matches the entered
   amount, log it as a billing amount error.

4. PATIENT ID FORMAT
   All Patient IDs must follow the format PAT-1XXXX (five digits starting with 1).
   Any ID not matching this format (e.g., PAT-0XXXX) is a confirmed data entry error.

5. QC REVIEW FLAGGING PROTOCOL
   When performing quality control reviews, categorize each finding as:
   - CLEAR ERROR: The entered value is definitively wrong (e.g., transposed digits,
     misspelled name, wrong code with wrong description).
   - REQUIRES REVIEW: The entered value may be correct under updated policy but needs
     supervisor confirmation (e.g., ICD-10 code that was valid before the policy change
     date but the service date falls after the change, or amounts that match the fee
     schedule but not the source form).
   Document CLEAR ERRORs in the error log. Document REQUIRES REVIEW items in a
   separate flagged_for_review log.

Questions about these updates should be directed to the Compliance Office.
