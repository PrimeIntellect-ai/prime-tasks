# openai/math challenge `RelativeGeneration` (family 296)

Prove the following result from OpenAI's [openai/math](https://github.com/openai/math) release in
Lean 4, with a proof the Lean kernel accepts.

Context: this statement belongs to family 296 of the release, *The generator problem for finite factors*
(Operator algebras). The family as a whole: Proves that every type $\mathrm{II}_1$ factor with separable predual is generated by a single operator, equivalently by two self-adjoint operators, resolving the generator problem. More strongly, for every irreducible inclusion $P\subset M$ of such factors, the unitaries $u$ with $M=W^*(P,u)$ form a dense $G_\delta$ subset in the trace $2$-norm topology.

The challenge is `RelativeGeneration`, also at `/opt/openai-math/challenges/RelativeGeneration.lean`:

```lean
import Mathlib

namespace OAI

noncomputable section

universe level

namespace RelativeGeneration

variable {Hilbert : Type level} [NormedAddCommGroup Hilbert]
  [InnerProductSpace ℂ Hilbert] [CompleteSpace Hilbert]

/-- Weak operator closedness of a concrete unital star subalgebra. -/
def WOTClosed (algebra : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert)) : Prop :=
  IsClosed {operator : Hilbert →WOT[ℂ] Hilbert | operator.toCLM ∈ algebra}

/-- The weakly closed unital star algebra generated by a set of operators. -/
def wstar (operators : Set (Hilbert →L[ℂ] Hilbert)) :
    StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert) :=
  sInf {algebra | WOTClosed algebra ∧ operators ⊆ algebra}

/-- A nonzero, weakly closed, finite diffuse algebra with scalar center. -/
structure IsII1Factor (algebra : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert)) : Prop where
  nonzero : (0 : Hilbert →L[ℂ] Hilbert) ≠ 1
  weaklyClosed : WOTClosed algebra
  factor : ∀ element : algebra, (∀ other : algebra, other * element = element * other) →
    ∃ scalar : ℂ, element = algebraMap ℂ algebra scalar
  finite : ∀ isometry : algebra, star isometry * isometry = 1 → isometry * star isometry = 1
  diffuse : ∀ projection : algebra, IsStarProjection projection → projection ≠ 0 →
    ∃ subprojection : algebra, IsStarProjection subprojection ∧ subprojection ≠ 0 ∧
      subprojection ≠ projection ∧ projection * subprojection = subprojection ∧
      subprojection * projection = subprojection

/-- A same-universe separable Banach predual, with the conjugate-linear dual convention.
This imposes no separability on the Hilbert representation or the operator norm topology. -/
def HasSeparablePredual (algebra : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert)) : Prop :=
  ∃ (Banach : Type level) (_ : NormedAddCommGroup Banach) (_ : NormedSpace ℂ Banach)
    (_ : CompleteSpace Banach) (_ : TopologicalSpace.SeparableSpace Banach),
    Nonempty (StrongDual ℂ Banach ≃ₗᵢ⋆[ℂ] algebra)

/-- The ultraweak topology is generated by absolutely summable vector functionals. -/
abbrev ultraweakTopology (Hilbert : Type level) [NormedAddCommGroup Hilbert]
    [InnerProductSpace ℂ Hilbert] [CompleteSpace Hilbert] :
    TopologicalSpace (Hilbert →L[ℂ] Hilbert) :=
  ⨅ (left : ℕ → Hilbert) (right : ℕ → Hilbert)
    (_ : Summable (fun index => ‖left index‖ * ‖right index‖)),
    TopologicalSpace.induced
      (fun operator : Hilbert →L[ℂ] Hilbert =>
        ∑' index, inner ℂ (left index) (operator (right index))) inferInstance

/-- The concrete algebra carries the induced ultraweak topology. -/
abbrev algebraUltraweakTopology (algebra : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert)) :
    TopologicalSpace algebra :=
  TopologicalSpace.induced (fun operator : algebra => (operator : Hilbert →L[ℂ] Hilbert))
    (ultraweakTopology Hilbert)

/-- A faithful normal normalized trace, not an additional hypothesis on the inclusion. -/
structure IsNormalizedTrace (algebra : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert))
    (trace : algebra →L[ℂ] ℂ) : Prop where
  normalized : trace 1 = 1
  positive : ∀ element : algebra, 0 ≤ (trace (star element * element)).re
  star_preserving : ∀ element : algebra, trace (star element) = star (trace element)
  tracial : ∀ left right : algebra, trace (left * right) = trace (right * left)
  faithful : ∀ element : algebra, trace (star element * element) = 0 → element = 0
  normal : @Continuous algebra ℂ (algebraUltraweakTopology algebra) inferInstance trace

/-- The normalized trace two-distance between genuine unitaries of the original algebra. -/
def traceDistance (algebra : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert))
    (trace : algebra →L[ℂ] ℂ) (left right : unitary algebra) : ℝ :=
  Real.sqrt (trace (star ((left : algebra) - (right : algebra)) *
    ((left : algebra) - (right : algebra)))).re

/-- The topology generated by trace two-distance balls, not the inherited operator norm topology. -/
abbrev traceTopology (algebra : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert))
    (trace : algebra →L[ℂ] ℂ) : TopologicalSpace (unitary algebra) :=
  TopologicalSpace.generateFrom {ball | ∃ center : unitary algebra, ∃ radius : ℝ,
    0 < radius ∧ ball = {point | traceDistance algebra trace center point < radius}}

/-- The entire relative-generator locus in the original unitary group. -/
def relativeGeneratorLocus (small large : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert)) :
    Set (unitary large) :=
  {element | wstar ((small : Set (Hilbert →L[ℂ] Hilbert)) ∪
    {((element : large) : Hilbert →L[ℂ] Hilbert)}) = large}

/-- Every irreducible inclusion of concrete type II₁ factors with separable predual
of the larger factor has a dense Gδ full relative-generator locus in the normalized
trace two-topology. The normalized faithful normal trace is asserted to exist;
no representation, transport, cyclicity, or perturbation premise is imposed. -/
def MainTarget : Prop :=
  ∀ (Hilbert : Type level) [NormedAddCommGroup Hilbert] [InnerProductSpace ℂ Hilbert]
    [CompleteSpace Hilbert] (small large : StarSubalgebra ℂ (Hilbert →L[ℂ] Hilbert)),
    IsII1Factor small → IsII1Factor large → ∀ inclusion : small ≤ large,
      (∀ element : large,
        (∀ member : small, StarSubalgebra.inclusion inclusion member * element =
          element * StarSubalgebra.inclusion inclusion member) →
        ∃ scalar : ℂ, element = algebraMap ℂ large scalar) →
      HasSeparablePredual large →
      ∃ trace : large →L[ℂ] ℂ, IsNormalizedTrace large trace ∧
        @IsGδ (unitary large) (traceTopology large trace) (relativeGeneratorLocus small large) ∧
        @Dense (unitary large) (traceTopology large trace) (relativeGeneratorLocus small large)

theorem main_theorem : MainTarget.{level} := by
  sorry

end RelativeGeneration

end

end OAI
```

## What to submit

Write `/workspace/Submission.lean`. Start from a copy of the challenge:

```bash
cp /opt/openai-math/challenges/RelativeGeneration.lean /workspace/Submission.lean
```

then replace every `sorry` with a proof. The file is graded on three things:

- **Same statements.** The theorem `OAI.RelativeGeneration.main_theorem` must keep exactly the statement shown above: same names,
  namespaces, binders and types. Every definition the statements use must stay exactly as written.
  Change nothing except the proofs.
- **Standard axioms only.** Proofs may use only `propext`, `Quot.sound` and `Classical.choice`.
  `sorry`, `admit`, new `axiom`s and `native_decide` (it introduces an axiom of its own) are rejected.
- **Keep the challenge's declarations as they are.** Put new lemmas and instances *after* the
  definitions the statements use, or in a separate `Submission/*.lean` module. A declaration added
  before them can change how they elaborate, and then they no longer match the challenge.
- **Kernel-checked.** The proofs are re-checked by the Lean kernel, not just the elaborator.

Long proofs can be split into modules under `/workspace/Submission/` (module names
`Submission.Foo`, `Submission.Foo.Bar`) imported from `Submission.lean`. Only `.lean` files at
those two paths are graded.

## Environment

- Lean `v4.34.1` and Mathlib at commit `d13f23b` are installed and prebuilt; `/workspace` is a
  Lake project.
- The sandbox has 4 CPUs and 8 GB of memory; `LEAN_NUM_THREADS=3` keeps `lake build` to three
  parallel jobs. Check your work with `cd /workspace && lake build Submission`. Add `#print axioms <name>` to see
  which axioms a proof uses.
- There is no internet access. OpenAI's own proofs are not installed.

## Grading

When you finish, `Submission.lean` and `Submission/**.lean` are copied to a fresh machine and
checked with [Comparator](https://github.com/leanprover/comparator), the Lean FRO's proof checker.
The reward is 1 if Comparator accepts the proof and 0 otherwise. A partial proof scores 0.
