Add support for socks5h proxies
I have started using git-lfs recently, and found, that accessing repositories through a socks5h server has become quite a headache. Git itself supports both socks5 and socks5h without problem, trying to resolve host names locally for socks5 and forwarding them to the socks server for socks5h. For what I'm doing, I need the latter, so I used to specify a socks5h proxy.
For some reason, golang chose not to support proxy URL starting with socks5h, only with socks5, but if you give it a socks5 URL, it actually does things the socks5h way and forwards all host names to the socks server. I found bug reports and change proposals to remedy this situation in golang, that were written two years ago. So I don't expect the situation to improve any time soon.
In the meantime, would it be possible to implement a workaround in git-lfs, that [HIDDEN]? Then I could set HTTPS_PROXY to socks5h://server:port and both git and git-lfs would do the same thing.
