FR: "ignore cased word" Should Affect First Letter Capitalization
## Describe the Bug

A clear and concise description of what the bug is.

## How to Reproduce

Steps to reproduce the behavior:

1. Go to "H1 heading" tab,
2. Check the "ignore cased word" option,
3. select the style to "First letter",
4. format

The word with upper case letters is still formatted as lower case letters.

## Expected Behavior

Only apply the "First letter" rule to the words with all lower case letters.
