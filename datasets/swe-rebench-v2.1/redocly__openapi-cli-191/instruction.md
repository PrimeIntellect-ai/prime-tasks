Bundle doesn't support OpenAPI yaml with $ref's
**Describe the bug**
Trying to run `openapi bundle -o openapi.json openapi.yaml` returns a heap of `cannot resolve $ref` errors. <br>
Running `openapi preview-docs` works fine though.

**To Reproduce**
Create any  YAML file with component refs (like schemas or routes) and try to bundle it.

**Expected behavior**
A bundled file

**Logs**
Exerpt:
```
[100] openapi.yaml:177:7 at #/components/schemas/Foo

Can't resolve $ref: ENOENT: no such file or directory, open '/home/user/MYPROJECT/docs/components/responses/components/schemas/foo.yaml'

175 |   $ref: "./components/schemas/object.yaml"
176 | Foo:
177 |   $ref: "./components/schemas/foo.yaml"
178 | Bar:
179 |   $ref: "./components/schemas/bar.yaml"

Error was generated by the bundler rule.
< ... 22 more problems hidden > increase with `--max-problems N`
```

**OpenAPI definition**
not possible

**Version(s)**
1.0.0-beta.8

**Additional context**
I'm looking for an easy way to run a yaml to json bundling through docker.
