Commons upload: newly uploaded cells should contain `File:` prefix in cell.recon.name
According to @sunilnatraj's analysis in https://github.com/OpenRefine/CommonsExtension/pull/153, newly-uploaded files get represented by matched reconciled cells whose `.name` field does not contain a `File:` prefix, contrary to matches returned by the reconciliation service (for existing files). It would be worth unifying those two.
If that's indeed the case, the simplest would be (I think) to change our upload code so that matched cells do contain the `File:` prefix. It could be that this breaks some workflows, if folks explicitly rely on those filenames not having the `File:` prefix, but I would expect downstream uses of uploaded files generally go through the Mids instead, so I think it would be fine to introduce such a change.
