Add header and footer template configs
When having multiple release drafts a nice feature would be `header` and `footer` templates. These should work exactly like the `template` config (you can also think of it like splitting the original `template` config into three parts).
The use case we have is that we want the same footer on each release note, no matter which repository in our organization gets released. In the footer we could thank our premium sponsors, add additional generic information (like support contact addresses), etc. Because different repos have different release notes bodies, we could put a `base.yml` release notes in our `.github` repo that contains the `footer` template and then we could just `_extend` from that base tempate, still giving each release draft the possibility to have it's own custom `template` config.
Right now we would have to add this information to each release draft, which obviously isn't really nice (specially if you have to add premium sponsors, you have to updated each draft instead of just one base draft).
