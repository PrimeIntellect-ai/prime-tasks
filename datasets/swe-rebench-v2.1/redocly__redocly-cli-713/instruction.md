Callbacks typing seems wrong
**Describe the bug**

The NamedCallbacks and Callback types seem wrong.

```js
  NamedCallbacks: mapOf('PathItem'),
```
[HIDDEN]


And

```js
const Callback = {
  properties: {},
  additionalProperties: 'PathItem',
};
```

This seems incorrect. The callback is a map of expression to `PathItem`. It seems it should be more similar to:

```js
  [HIDDEN]
```


**To Reproduce**
Steps to reproduce the behavior (minimal definition):

```yaml
openapi: 3.1.0
info:
  title: Callback test
  version: 'alpha'
components:
  callbacks:
    resultCallback:
      '{$url}':
        post:
          requestBody:
            description: Callback payload
            content:
              'application/json':
                schema:
                  type: object
                  properties:
                    test:
                      type: string
          responses:
            '200':
              description: callback successfully processed

```

Run `openapi lint`.

```
Property `{$url}` is not expected here.

 7 |   resultCallback:
 8 |     '{$url}':
 9 |       post:
10 |         requestBody:

Error was generated by the spec rule.
```

**Expected behavior**
I expected that the callback is correct. If not, what is wrong?
