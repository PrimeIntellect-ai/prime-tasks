tag: {{Merge to}} combined with an article section has incorrect "Discuss" link
When doing {{Merge to}} to a section, e.g. Wii Menu#Nintendo Channel, the following code is generated:

`{{Merge from|Nintendo Channel|discuss=Talk:Wii Menu#Nintendo Channel#Proposed merge of Nintendo Channel into Wii Menu#Nintendo Channel|date=February 2022}}`

This leads to a buggy discuss link. The code should instead be

`{{Merge from|Nintendo Channel|discuss=Talk:Wii Menu#Proposed merge of Nintendo Channel into Wii Menu#Nintendo Channel|date=February 2022}}`

Twinkle places this tag on both articles, so tag needs to be fixed in both places.

Should also check the {{Merge from}} and {{Merge}} code for this. Likely has the same issue.

### Additional contract requirements

- When {{Merge to}} targets a section of an article, the Discuss link generated on the article carrying {{Merge to}} must not repeat that section in the article part of the link. The article part names only the page, and the section appears only in the discussion title, as in the corrected example above.
- The other article tagged in the same merge (which receives the matching {{Merge from}} tag) must carry the same corrected Discuss link.
- The Discuss link generated by {{Merge from}} and {{Merge}} tags must likewise not repeat a section in the article part of the link. Their Discuss link names the article carrying the tag, without a section.
