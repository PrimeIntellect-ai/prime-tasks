Is there a way to post process the generated CRD?
I'd like the generated CRD to include logical constraints using [ "oneOf", "allOf", "anyOf", "not" ]. Currently I don't believe this is something the generator can provide. If there is a way to post process the generated CRD before its applied that could offer a pathway to include these constraints.

Related:
https://github.com/fabric8io/kubernetes-client/issues/6801

### Additional contract requirements

- A user can supply a post-processing step for generated CRDs by setting the configuration property `quarkus.operator-sdk.crd.post-processor` to the fully qualified class name of a class implementing the Fabric8 CRD generator v2 `CRDPostProcessor` interface. The class must provide a public no-arg constructor.
- The post-processing step runs on each CRD generated by the build, so the changes it makes to a generated CRD (for example, adding `oneOf`, `allOf`, `anyOf` or `not` constraints to the schema, or labels to its metadata) appear in the generated CRD manifest.
