"Bad substitution error" when using other shell than bash
With version 0.12, I get a `Bad substitution` error when trying to use scripts generated by Comonicon.
The problem is fixed when I specifically use bash to call the script, *i.e.* calling  `treeknit --help` results in an error, whereas calling `bash treeknit --help` works just fine (the package I try this on is https://github.com/PierreBarrat/TreeKnit.jl).
When downgrading to v0.11.7, there is no error at all.

[HIDDEN]
But on Ubuntu, `/bin/sh` points to `dash` (at least on me and my colleagues machines...). Hence the error.
