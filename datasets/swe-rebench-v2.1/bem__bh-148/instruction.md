jsElem
Add ability to parametrize addition of `i-bem` classname for elems with js params.

If `jsElem: true` then add `i-bem` class for blocks and elems.
If `jsElem: false` then add `i-bem` class only for blocks.

See:

* https://github.com/bem/bh/issues/119
* https://github.com/enb-bem/enb-bh/issues/26
