Notice and skip emojis and HTML entities
First of all, this plugin is life-changing for my team of lazy devs :joy:

But then, we noticed we every now and then need to use the (verbose) `eslint-disable` comment in places that really don't need to be translated, namely strings composed of emojis or entities/symbols (such as the infamous `&times;` for popup closure).

It would be great if the plugin was able to identify that and skip notifying.
