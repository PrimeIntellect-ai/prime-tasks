[Feature Request] Default currency for currency converter
In v8 we could set the default currency, let's say EUR.

So instead typing:

```
10 usd to eur
```

it was enough to just type:


```
10 usd
```

That was super helpful and fast to convert currencies. Please consider adding back this option, thanks! 🙌

### Additional contract requirements

- The extension's settings panel must expose a control that lets the user choose the default target currency, and it must display the currently configured default target currency.
