Possibly force or add a flag to force directories to be returned with trailing slash (glob)
`globmatch`  (when `REALPATH` is not enabled) only recognizes a path as being a directory if the filename ends with a trailing slash. `glob` only really returns a path with a slash when knows the file is a directory because it explicitly checked. This is similar to how bash can at times return a directory with or without a trailing slash depending on the pattern it is given. It may be useful to add a flag to force a directory to be returned with a slash. This would require additional `stat` calls in places we may not be calling `stat`. For this reason, I think this should be optional.
