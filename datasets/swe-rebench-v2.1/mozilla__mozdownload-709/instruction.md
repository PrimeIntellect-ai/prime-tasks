Use tar.xz archives for Linux if available by default
As the following blog post explains the downloadable builds for Firefox switched from `tar.bz2` to `tar.xz`. We should update mozdownload to support this file extension and at least for newer builds prefer this extension over `tar.bz2`.

https://blog.nightly.mozilla.org/2024/11/28/announcing-faster-lighter-firefox-downloads-for-linux-with-tar-xz-packaging/
