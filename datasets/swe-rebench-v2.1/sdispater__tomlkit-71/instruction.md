Apostrophe (single-quote) in key string causes problems
This code sequence demonstrates the problem:
```
import tomlkit

dat = {"BJ's Restaurant": {'account':'dining'}}

toml = tomlkit.dumps(dat)
print(toml)

dat2 = tomlkit.loads(toml)
```

The TOML generated by dumps(dat) shows in the first two lines, and seems correct. However loads() blows up as shown, calling out column 18 which would be the end of the key string.
