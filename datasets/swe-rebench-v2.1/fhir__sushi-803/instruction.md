Support elementdefinition-profile-element extension
The [elementdefinition-profile-element extension](http://hl7.org/fhir/R4/extension-elementdefinition-profile-element.html) refers to the:
> specific element to use in the referenced profile. This is used when a backbone element is being profiled, rather than an established type.

More specifically, it can be used to indicate that content reference element should take on the constraints of the thing that it targets.  See: https://chat.fhir.org/#narrow/stream/179252-IG-creation/topic/Clarification.20on.20contentReference/near/225076962
