Add "Refresh" button for each tab
I'm experiencing regular hangs, or bad view renders for several apps inside ElectronIM.  Would be very helpful if there was a "Refresh" button to force an app url to reload and hopefully resolve the problems.   Currently the only way to do that is to restart the app.

### Additional contract requirements

- The refresh capability for each tab is provided through the tab's context menu.
- Each tab's context menu must include an entry labeled "Reload" that reloads the tab's app URL.
