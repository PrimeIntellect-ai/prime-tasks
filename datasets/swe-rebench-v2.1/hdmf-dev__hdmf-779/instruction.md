[Bug]: Autogenerated MultiContainerInterface.__init__ errors when optional args missing
### What happened?

When I call __init__ on an autogenerated MultiContainerInterface, and do not pass in an optional argument that is one of the "multi-container" attributes of the class, then the add method is called on None, and an error is raised from docval.

```
TypeError: MultiContainerInterface.__make_add.<locals>._func: None is not allowed for 'acquisition__nwb_data_interfaces' (expected 'list, tuple, dict or NWBDataInterface', not None)
```

### Steps to Reproduce

```shell
Try to autogenerate an NWBFile
```
