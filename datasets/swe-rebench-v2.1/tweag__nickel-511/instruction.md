Non-serializable error on top-level term shows no location
**Describe the bug**
If the top-level term one is trying to serialize (e.g. via `nickel export`) isn't serializable (typically a function), the "non-serializable term" error doesn't show any position, which makes it hard to understand where is the problem. This can typically happen when a function is not fully applied:

**To Reproduce**
```
// gen.ncl
fun param1 param2 => {
  foo = param1,
  bar = param2,
}

$nickel export <<< 'import "gen.ncl" "fooval"'
error: non serializable term
  ┌─ <unknown> (generated by evaluation):1:1
  │
1 │ <func>
  │ ^^^^^^
```

**Expected behavior**
The error should show the correct location of the function inside `gen.ncl`, as it does already for any term that is not the root node of the AST.
