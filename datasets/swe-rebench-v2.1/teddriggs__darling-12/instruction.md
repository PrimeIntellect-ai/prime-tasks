Struct and newtype enums should appear in error paths from derived impls
When an enum with non-unit variants derives `FromMetaItem`, the ident of the non-unit variant will form part of the path in the input source. A user would expect to see that ident in an error path generated by darling.

### Additional contract requirements

- When deriving `FromMetaItem` for an enum, variant names are matched using snake_case by default.
