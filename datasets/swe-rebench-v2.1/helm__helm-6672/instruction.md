Stack overflow in pkg/chartutil/errors.go
`pkg/chartutil/errors.go` has a recursion bug which results in a stack overflow when trying to serialize the value of the error:

https://github.com/helm/helm/blob/dev-v3/pkg/chartutil/errors.go#L26

If you attempt to render one of these Errors, you'll get a stack overflow. I have proposed a unit test in #6672 which demonstrates the stack overflow.
