Provide Azure Function-based templates as part of the create command
## Description

It would be helpful to have Azure Functions-based templates as part of the `create` command, in order to support a simplified getting started experience, without needing to `install` a custom Git repo.

This would allow end-users to simply run something like `sls create -t azure-nodejs`, which is easy to discover (thanks to the help text for the `create` command), and very ergonomic.
