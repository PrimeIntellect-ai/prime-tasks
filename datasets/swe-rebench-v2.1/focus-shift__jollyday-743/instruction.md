Switzerland: Berchtold's Day as bank holiday for ch
### Affected country

Switzerland

### Affected public holiday

Berchtold's Day

### Source of the information

https://de.wikipedia.org/wiki/Feiertage_in_der_Schweiz#Nationale_und_allgemeine_Feiertage

### More information

As part of #655, which aimed to improve Switzerland according to https://en.wikipedia.org/wiki/Public_holidays_in_Switzerland, Berchtold's day was removed from Cantons that correctly had it configured:

* Glarus
* Luzern
* Neuchâtel
* Solothurn
* Zug
* Zürich

Instead, it should have been added to the ones for which it is still missing:

* Jura
* Obwalden

### Additional contract requirements

Berchtold's Day is a bank holiday (`HolidayType.BANK_HOLIDAY`) for Switzerland as a whole, and it is available for the cantons Glarus, Luzern, Neuchâtel, Solothurn, Zug, Zürich, Jura and Obwalden.
