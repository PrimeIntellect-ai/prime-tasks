[SelectInput]  When the user clicks in the arrow, the cursor it not placed on the field.
## Component to amend
SelectInput

## Context
As our tests results showed, many users used to open the select field by clicking on the arrow and then, start typing.
It would help if the cursor was positioned in the field, after clicking on the arrow.
