exclude refinement results doesn't check whether the mainSubResponse.facets exist
We call this unconditionally, meaning that when a wrong result (eg fake one from React InstantSearch Hooks) is used, this throws an error. [HIDDEN]

```js
  // add the excludes
  Object.keys(state.facetsExcludes).forEach(function(facetName) {
    var excludes = state.facetsExcludes[facetName];
    var position = facetsIndices[facetName];

    self.facets[position] = {
      name: facetName,
      [HIDDEN]
      exhaustive: mainSubResponse.exhaustiveFacetsCount
    };
    excludes.forEach(function(facetValue) {
      self.facets[position] = self.facets[position] || {name: facetName};
      self.facets[position].data = self.facets[position].data || {};
      self.facets[position].data[facetValue] = 0;
    });
  });
```

### Additional contract requirements

- Processing exclude refinements must not throw when the result lacks facet data.
- An excluded facet value must still be represented with a count of zero when the result lacks facet data.
