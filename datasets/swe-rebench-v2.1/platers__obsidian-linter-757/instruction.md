Bug: Numerical aliases need to be quoted to work
## Describe the Bug

Purely numerical aliases (e.g. `20230603151900`) need to be quoted to make them work in obsidian. The linter doesn't pick this up, yet.

## How to Reproduce

Steps to reproduce the behavior: See [this forum post](https://forum.obsidian.md/t/cannot-use-uid-as-alias/20306/3). The described behavior is still found in today's Obsidian.

## Expected Behavior

Purely numerical aliases are quoted to make them valid (e.g. `"20230603151900"`).

- [x] Desktop
- [x] Mobile
