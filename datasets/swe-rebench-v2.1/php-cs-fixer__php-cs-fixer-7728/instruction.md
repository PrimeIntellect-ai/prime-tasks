Invalid return generated by `simplified_null_return` with union typehint
## Bug report

### Description

When a function has `null|array` return typehint and the code return `null`, the `simplified_null_return` removes the `null` keyword, which generates an invalid code

> Compile Error: A function with return type must return a value (did you mean "return null;" instead of "return;"?)

Here is a minimal reproducer

```php
    public function test(): null|array
    {
        if (true) {
            return null;
        }

        return [];
    }
```

Php-cs-fixer tries to patch this like

```patch
         if (true) {
-            return null;
+            return;
         }
 ```
