URLs without scheme produce relative links
Homepages / SCM URLs in `pom.xml`s or `ivy.xml`s without a scheme produce broken relative links in PR bodies. One example is https://github.com/sangria-graphql-org/sangria-msgpack/pull/15. The [msgpack-core POM](https://repo1.maven.org/maven2/org/msgpack/msgpack-core/0.8.20/msgpack-core-0.8.20.pom) contains `github.com/msgpack/msgpack-java.git` as SCM URL which is then interpreted as relative link in the PR body pointing to `https://github.com/sangria-graphql-org/sangria-msgpack/pull/github.com/msgpack/msgpack-java.git` which of course does not exist. I think we should just reject URLs without a scheme in `[HIDDEN]`.
