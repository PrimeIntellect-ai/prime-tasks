Capitalize Headings rule is applied to lines that start with a tag
With the option enabled, this text
```
# title

This note is #incomplete because I was distracted

#incomplete because I was distracted
```
turns into this
```
# Title

This note is #incomplete because I was distracted

#incomplete Because I Was Distracted
```

The rule shouldn't have applied it to the last line, which starts with a tag. (No space after #)
