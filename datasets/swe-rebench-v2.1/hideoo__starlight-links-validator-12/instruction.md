Doesn’t account for multiple headings with the same text
### Describe the bug

Given a Markdown document with headings containing the same text, for example like this contrived one:

```md
## Heading

## Heading
```

`github-slugger` will auto-increment and attach an integer to the end of the generated `id`. So the above Markdown generates the following HTML:

```html
<h2 id="heading">Heading</h2>
<h2 id="heading-1">Heading</h2>
```

[HIDDEN]


### To Reproduce

1. Create a document with headings containing the same text.
2. Link to one of the later headings (e.g. with a `-1` suffix).
3. Run the link validator.
4. It will error and flag the `-1` link.

### Expected behavior

Link anchor slugging logic should match the Astro project’s logic and the validation should pass.

### How often does this bug happen?

Every time

### System Info

Observed on macOS, but I suspect that’s not relevant.
