Support multi-line values
[bkeepers/dotenv](https://github.com/bkeepers/dotenv), [motdotla/dotenv](https://github.com/motdotla/dotenv), [python-dotenv](https://github.com/theskumar/python-dotenv) and [stackbuilders/dotenv-hs](https://github.com/stackbuilders/dotenv-hs) support multi-line values. For example:

```bash
MULTILINE="new\nline"
```
