`a = [ 3, 4]` deve inicializar uma lista na variável a
```potigol
a = [ 3, 4]
escreva(a)
escreva(a.qual_tipo)
```


![Image](https://github.com/DesignLiquido/delegua/assets/3980593/6601e5b0-192b-4049-a4ac-f8b1e65f8ad3)

### Additional contract requirements

- Ao executar `escreva(a)` para a lista `[3, 4]`, a saída deve ser exatamente `[3, 4]`.
- - Ao executar `escreva(a.qual_tipo)` para a lista `[3, 4]`, a saída deve ser uma string não vazia.
