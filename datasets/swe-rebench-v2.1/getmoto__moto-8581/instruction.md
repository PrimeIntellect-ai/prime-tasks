Cognito-IDP missing default claims in access token
[Default claims](https://docs.aws.amazon.com/cognito/latest/developerguide/amazon-cognito-user-pools-using-the-access-token.html) are missing in the `create_jwt` method:

https://github.com/getmoto/moto/blob/7536c084790fd8db44ceaa34bb1a3ce757509782/moto/cognitoidp/models.py#L521-L537

When comparing to the AWS docs (see link above), these fields are missing:
- `device_key`
  - not documented on the page I linked to
- `version`
  - not documented on the page I linked to
- `origin_jti`
- `event_id`
- `scope`
- `iat`
- `jti`

### Additional contract requirements

- Every access token issued by the Cognito IDP emulator, including access tokens returned after a refresh-token flow and after a new sign-in, contains an `origin_jti` claim whose value is a non-empty string.
- Every access token issued by the Cognito IDP emulator contains a `jti` claim whose value is a non-empty string, and two separately issued access tokens never share the same `jti` value.
