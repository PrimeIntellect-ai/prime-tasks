Update Charts to latest version
### Description

Update the version in the latest zookeeper and zookeeper operator charts

### Importance

must-have

### Location

Charts

### Suggestions for an improvement

Update the charts

### Additional contract requirements

- The chart version of both the zookeeper chart (`charts/zookeeper/Chart.yaml`) and the
  zookeeper-operator chart (`charts/zookeeper-operator/Chart.yaml`) must be updated to
  `0.2.14`. The chart version is the `version` field of each chart's `Chart.yaml`.
