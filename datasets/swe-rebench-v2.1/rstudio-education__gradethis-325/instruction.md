`grade_this_code()` duplicates feedback when `gradethis_setup(fail.hint = TRUE)`
When `gradethis_setup(fail.hint = TRUE)`, `grade_this_code()` provides the same feedback twice when given an incorrect answer. [HIDDEN]

``` r
library(gradethis)
ex <- mock_this_exercise(.user_code = "sqrt(log(2))", .solution_code = "sqrt(log(1))")

gradethis_setup(fail.hint = FALSE)
grade_this_code()(ex)
#> <gradethis_graded_this_code: [Incorrect]
#>   In `log(2)`, I expected `1` where you wrote `2`. That's okay: you
#>   learn more from mistakes than successes. Let's do it one more time.
#> >

gradethis_setup(fail.hint = TRUE)
grade_this_code()(ex)
#> <gradethis_graded_this_code: [Incorrect]
#>   In `log(2)`, I expected `1` where you wrote `2`. Try it again. You
#>   get better each time. In `log(2)`, I expected `1` where you wrote
#>   `2`.
#> >
```

## Possible solution
[HIDDEN]

### Additional contract requirements

- The `fail.hint` setting is controlled by the `gradethis.fail.hint` option.
- For an incorrect answer, the feedback generated by `code_feedback()` must appear exactly once in the message returned by `grade_this_code()`, including when `gradethis.fail.hint` is `TRUE`.
