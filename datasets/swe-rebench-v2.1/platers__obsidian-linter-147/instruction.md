"First Letter" Capitalize headings option not working as expected
The "Capitalize Headings" option for formatting headings with the style "First Letter" works by *only* changing the first letter to upper case if it is lower case, however I would have expected this to also remove capitalization from words other than the first word. Example:

```
# this Is A Heading
```

Output:

```
# This Is A Heading
```

Expected output:

```
# This is a heading
```

I'm not sure if this is an intentional feature or a bug, but if it is intentional maybe there could be an additional option to format it the expected way? Thanks.
