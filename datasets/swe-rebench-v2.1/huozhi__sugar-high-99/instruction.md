Issue with a typical tailwind data-attribute selector: `data-[something=value]`
Hi.
I've noticed an issue where sugar-high would cut off a character from source.



Given a string like this:

```tsx
<div className="data-[layout=grid]:grid" />
```

highlight outputs this (note the char before `=` missing):

```tsx
<div className="data-[layou=grid]:grid" />
```
