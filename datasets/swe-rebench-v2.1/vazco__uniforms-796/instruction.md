Feature: Missing JSON Schema properties
While implementing a form based on JSON Schema generated by [pydantic](https://github.com/samuelcolvin/pydantic/). I noticed a few JSON Schema properties that are not handled. See also [their docs](https://pydantic-docs.helpmanual.io/usage/schema/#json-schema-types) about JSON Schema properties.

I am not sure about the supported JSON Schema specs and whether these properties are in scope of being supported by default. And I am not sure if it is a valid asumption that `const` is read only. But I feel at least some might be worth to implement in the base JSONSchemaBridge.

### Additional contract requirements

- For a field with `maxItems`, expose its value as `maxCount` in the computed props and omit `maxItems` from those props.
- For a field with `minItems`, expose its value as `minCount` in the computed props and omit `minItems` from those props.
- For a field with `maximum`, expose its value as `max` in the computed props and omit `maximum` from those props.
- For a field with `minimum`, expose its value as `min` in the computed props and omit `minimum` from those props.
- For a field with `multipleOf`, expose its value as `step` in the computed props and omit `multipleOf` from those props.
