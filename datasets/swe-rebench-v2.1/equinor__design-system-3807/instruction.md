Prefill filter values with column's min/max in EDS Data Grid
**Is your feature request related to a problem? Please describe.**

Our users were confused that filtering values have placeholder value 0 in the EDS data grid. They wondered if the filtering values were defined as from 0 to 0, which shouldn't give any results.

**Describe the solution you'd like**

I would suggest leaving the spaces empty or have the min/max values in the column as placeholders (The same as in parenthesis above filtering input fields, these are quite useful for us!)

**Additional context**

I thought of just fixing it in our app, but perhaps this is something useful for more than just our project?
