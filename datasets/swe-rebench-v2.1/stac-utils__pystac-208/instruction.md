PyStac Sometimes Removes Characters from URIs
Hello,

I have noticed that when getting absolute hrefs from PyStac (via `catalog.make_all_asset_hrefs_absolute()` or similar) PyStac sometimes loses key parts of non-local-fileystem paths.

In particular, I noticed this when using a catalog root of `/vsitar//tmp/catalog.tar/catalog.json`.  The absolute URIs that are returned are of the form `/vsitar/tmp/catalog.tar...` with the critical second `/` between `/vsitar` and `/tmp` missing (it is not a valid GDAL path with the slash removed).  This behavior seems to be generated by [this line](https://github.com/stac-utils/pystac/blob/cf804c370b79b4d2d1e6faf689eb915a9d7ed32c/pystac/utils.py#L110).

This behavior is possible to work around, but I wonder if it is possible to change this?

Thank you.
