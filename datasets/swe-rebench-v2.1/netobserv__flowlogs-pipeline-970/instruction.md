### Additional contract requirements

The Loki writer configuration (`api.WriteLoki`) exposes two additional fields:

- `Format string`: selects how each log line is represented. Supported values are `"json"` (the default when unset), which emits the record as a JSON object; `"fields"`, which emits each field of the record on its own key/value line; and `"printf"`, which emits the record using Go's default `%v` formatting.
- `Reorder bool`: when true, the keys of a JSON record are emitted in alphabetical order.

The standard-output writer configuration (`api.WriteStdout`) exposes a `Format string` field selecting how each record is represented: `"json"` emits the record as a JSON-encoded object, `"fields"` emits each field of the record on its own key/value line, and any other value (including the empty default) emits the record using Go's default `%v` formatting.
