Good morning! Here's your coding interview problem for today.

This problem was asked by YouTube.

Write a program that computes the length of the longest common subsequence of three given strings. For example, given "epidemiologist", "refrigeration", and "supercalifragilisticexpialodocious", it should return 5, since the longest common subsequence is "eieio".

### Additional contract requirements

In package `day209`, provide an exported function `LengthLongestCommonSubseqOf3Recursive(one, two, three string) int`. It returns the length of the longest subsequence common to all three input strings. Its result for the example above is 5. The function may use any approach to compute the result.
