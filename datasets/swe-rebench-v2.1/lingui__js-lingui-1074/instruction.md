Built PO file contains header with incorrect letter case
**Describe the bug**
Extracting PO file generates a file containing the header "Mime-Version: 1.0\n".

**Expected behavior**
Extracting PO file should generate a file containing the header "MIME-Version: 1.0\n" (note the difference in letter case).

**Additional context**

- jsLingui version ``lingui --version``: 3.9.0
- Babel version ``npm list @babel/core`` 7.14.3

"MIME-Version: 1.0\n" seems to be the correct case (http://pology.nedohodnik.net/doc/user/en_US/ch-poformat.html).

When opening a file generated by lingui with Poedit, a new header "MIME-Version: 1.0\n" is written in addition to the one already in the file ("Mime-Version: 1.0\n"). That creates unnecessary diff in git.
