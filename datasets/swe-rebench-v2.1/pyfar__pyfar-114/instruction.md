Some numpy aliases of builtin type deprecated
## Description

Since numpy version 1.20.0, the some builtin type aliases are deprecated. Pyfar contains a fair number of `np.int` for example. The deprecated aliases need to be replaced by their equivalent builtin types or numpy types
with corresponding precision. See release notes [here](https://numpy.org/devdocs/release/1.20.0-notes.html#deprecations)
