Redirect to stack URL when note is moved into stack
Currently when in StackView and the viewed note gets moved into a stack (while not being the parent note), the URL does not change and the StackView is showed as if the viewed note is the parent note (aka. the note is not stacked).

I think it would be intuitive to redirect to the StackView URL so that the current state of the note is mirrored (as in "the note becomes a child note in a stack")
