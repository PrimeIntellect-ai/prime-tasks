Add 'shake' text chunk effect
Now there is a new, text chunk capable, text effects system it should be possible to build a 'shake' effect (similar to a screen shake) for this system.

Original issue comment mentioning shake effect:

https://github.com/MyreMylar/pygame_gui/issues/24#issuecomment-582462344

Screen shake effect example code:
https://jonny.morrill.me/en/blog/gamedev-how-to-implement-a-camera-shake-effect/

I will link the text effects code later once 0.6.0 is merged in.

### Additional contract requirements

A shake text effect must be usable on an effect-tagged text chunk and make that chunk's position vary over time.
