namespace + extends not working
## Bug description

When using `extends` inside `namespace`, there's an error:

```
// Without namespace, this works:
export interface BaseObject {
  "id": string;
}
export interface Object extends BaseObject {
  "name": string;
}

// With namespace, this will fail:
export namespace std {
  export interface BaseObject {
    "id": string;
  }
  export interface Object extends BaseObject {
    "name": string;
  }
}
```

Error with namespace:
```
 ›   Warning: Some schemas can't be generated due to circular dependencies:
 ›   stdObjectSchema
✔ Validating generated types
🎉 Zod schemas generated!
```

Only `BaseObject` get generated:
```ts
// Generated by ts-to-zod
import { z } from 'zod'

export const stdBaseObjectSchema = z.object({
  id: z.string(),
})
```

Without namepsace everything's good:
```ts
// Generated by ts-to-zod
import { z } from 'zod'

export const baseObjectSchema = z.object({
  id: z.string(),
})

export const objectSchema = baseObjectSchema.extend({
  name: z.string(),
})
```

**Versions**

ts-to-zod/1.13.1 wsl-x64 node-v19.3.0

### Additional contract requirements

When an interface inside a namespace extends another interface in that same namespace, schema generation must include a schema for the extending interface rather than report it as circular. The generated schema must represent the fields inherited from its base interface as well as fields declared on the extending interface.
